# entangle-run Organization Profile

This repository defines the public GitHub organization profile and default
community health files for `entangle-run`.

The product source of truth is:

- `entangle-run/entangle` for the runtime;
- `entangle-run/entangle-website` for the public website and docs.

Entangle should be described consistently as a self-hosted federated runtime
for observable coding-agent organizations. Same-machine deployment is a
developer profile, not a product identity.

## Files

- `profile/README.md` — public organization profile.
- `CONTRIBUTING.md` — default contribution guidance.
- `SECURITY.md` — default security reporting policy.
- `SUPPORT.md` — support and contact guidance.
- `PULL_REQUEST_TEMPLATE.md` — default PR checklist.
- `ISSUE_TEMPLATE/` — default issue templates.
