# Support

Entangle is pre-release. Public support is currently best-effort through GitHub
issues and discussions when enabled on the relevant repository.

Use:

- `entangle-run/entangle` for runtime, CLI, Studio, runner, Host, deployment,
  and protocol issues;
- `entangle-run/entangle-website` for website and public documentation issues;
- `security@entangle.run` for security reports.

When reporting runtime problems, include the command you ran, relevant Host or
runner logs, git commit, operating system, Node.js version, Docker version, and
whether the run used fake providers or real LLM credentials.
