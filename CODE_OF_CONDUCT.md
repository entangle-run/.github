# Code of Conduct

Entangle is an open-source project for building observable coding-agent
organizations. Collaboration should stay technical, respectful, and evidence
oriented.

## Expected Behavior

- Be direct without being hostile.
- Critique ideas, code, architecture, tests, and documentation rather than
  people.
- Keep discussions relevant to the project.
- Make claims with evidence when possible.
- Respect security-sensitive reports and private operational data.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks.
- Publishing private information without consent.
- Deliberately derailing technical discussions.
- Misrepresenting test, security, or production-readiness evidence.

## Reporting

Report conduct concerns to `security@entangle.run` if they involve security or
private information. For ordinary project moderation, open a GitHub issue in
the relevant repository when appropriate.

Project maintainers may remove comments, close issues, block users, or take
other reasonable action to protect the project.
